# 参考用的真实汇报

这两份是真实的北大学生汇报，作为版式参考收在这里（原样保存，未改动）：

- `Copy of Li-S Battery.pptx` —— 组会文献汇报的切片（PART 03 章节页 + 8 页内容页）
- `材料物理汇报MoS2.pptx` —— 文献汇报（封面 + 9 页内容 + "谢谢"页）

`skills/paper-slides/scripts/assets/` 下的三张素材就是从这两份的 `ppt/media/` 里导出的原件：

| 素材 | 来自 | 原始尺寸 |
|---|---|---|
| `pku-landmarks.png` | MoS2 `image5.png` | 1398×907 RGBA，透明底、自上而下 alpha 渐隐 |
| `pku-honeycomb.png` | Li-S `image1.png` | 1200×1500 RGBA，主色约 6% 压白 |
| `pku-campus.png` | MoS2 `image29.png` | 3840×2160 灰度，最暗仅 223/255 |

拆解结论写在 `skills/paper-slides/references/design-system.md` 的「背景层」一节：
它们的母版与版式**都是纯白**，所谓背景全部画在页面自身上，语法只有
"一块实色 + 一片同色系 6%–12% 浓度的区域"，且**只有首尾页有，内容页一律纯白**。
