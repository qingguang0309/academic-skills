# 设计系统与中文排版规则

slidekit.js 已把这里的大多数规则做成机制;本文档解释"为什么",以及少数需要作者自己判断的地方。

## 画布与网格

- 16:9 宽屏,13.33 × 7.5 in(`LAYOUT_WIDE`)。国内会议室与线上会议的绝对主流。
- 左右边距 0.72 in,内容区宽 12.0 in;内容区底界 6.88 in,页脚基线 7.06 in。
- 块间距 0.26 in;双栏列间距 0.45 in。所有页面同一网格——观众感知不到网格,但感知得到"每页都很稳"。

## 字阶(pt,13.33 in 画布)

| 角色 | 字号 | 说明 |
|---|---|---|
| 封面主标题 | 36 | 粗体,白字,最多三行 |
| 页标题 | 25 | 粗体,主色,单行;只点明主题,中文约 18 字以内,超长或像句子 slidekit 会警告 |
| 章节页大号数字 | 96 | 极浅主题色,当背景图形用 |
| 章节标题 | 30 | 粗体 |
| 正文 | 17 | 溢出时布局引擎最多降到 ×0.85 |
| 辅文/卡片正文 | 12.5–14 | |
| 图注/表注 | 11.5 | 灰色,居中 |
| 页脚 | 9.5 | 极浅灰,存在但不打扰 |

层级只靠字号 + 字重 + 颜色,不靠换字体。全 deck 一套中文字体 + 一套西文字体。粗体只给标题、导语和数值,不整段加粗(`text` 块整段加粗 slidekit 报警);文字放不下时先删字,再考虑缩字号(引擎自动降字号时会报警)。

## 主题与用色纪律

五套内置主题(THEMES):`azure` 藏青·金(通用)、`pine` 墨绿·赭(材料/能源)、`plum` 绛紫·杏(生医/化学)、`claude` 赤陶·暖砂、`pku` 北大红·燕园金(北大红 `#94070A` + 燕园金 `CEAB6E`)。每套 = 深主色 + 中亮强调色 + 一个暖色点缀 + 灰阶。字体统一 Microsoft YaHei + Arial。

### `pku` 主题 = 北大答辩版式(含校徽)

`pku` 主题在答辩/结题场合(`kind` 为 `defense`/`grant` 或不传)默认走整套北大答辩版式,白底 + 北大红 `#94070A`:

| 页型 | 版式 | 对应选项 |
|---|---|---|
| 封面 | 白底;左上校标;中部红带放场合、题名、副题;底部红带放汇报人 / 指导教师 / 单位与日期 | `coverStyle:"ribbon"` |
| 内容页 | 左上红色章节号块 + 黑色粗体页题 + 通栏红线 + 右上校徽;页题下结论条;按需的页底红底白字结论横条 | `headerStyle:"numbered"` |
| 章节页 | 只留章节列表,当前章用红色章节号块 + 红色大字高亮,其余章灰色;不放章节说明、要点、页脚等灰色小字 | `sectionStyle:"list"` |
| 结束页 | 中部红带 + 白色校徽 + "敬请各位老师批评指正" | `closingStyle:"ribbon"` |

这四个选项任何主题都可以单独打开或覆盖(例如 azure 主题也可以用 numbered 页眉,色块与线跟随该主题的主色);组会/文献汇报场合的 `pku` 仍走 plate 封面与经典结束页。

资源在 `scripts/assets/`(与 slidekit.js 同级,校徽从官方模版矢量抽出、统一到北大红 `#94070A`、透明底):

- `pku-logo.png` 印章 + 校名横排锁定版(北京大学 + PEKING UNIVERSITY)—— ribbon 封面左上角,内容页/目录/章节/参考文献页右上角,等高缩放不变形。
- `pku-seal-white.png` / `pku-logo-white.png` 白色版 —— ribbon 结束页红带上的白色校徽。
- `pku-seal.png` 红色圆形印章 —— band 封面(白—红—白三段带 + 居中印章)用。

机制由 slidekit 的 `_resolveBrand` 自动接管:选 `pku` 主题即默认引用这些文件(须把 `assets/` 随 `slidekit.js` 一起复制进用户项目,缺了 build 时报警)。可用 Deck 选项覆盖:`logo` / `seal` / `logoWhite` / `sealWhite` 传自定义路径,`coverStyle` 换封面变体(`ribbon` / `split` / `plate` / `band` / `solid`),`cornerLogo:false` 关角标,任一传 `false` 关掉;文件缺失静默跳过、不报错。其它主题不带资源,行为不变。

官方模版里的西门石狮、博雅塔满版照片属装饰性满版图,与本 skill"内容页禁满版图"的纪律冲突,故不并入,需要时按 figure 块单独引用。

- **深主色**只用于:封面/结束页底色、页标题、表格粗线、章节标题。
- **强调色**只用于:数字编号、大数字卡数值、章节导航当前项、callout 标签——即"要观众先看"的地方。
- **母题是排版规则,不是装饰色块。** 全 deck 的视觉签名由三种"线"承担:目录/结束页标题下的短标尺线(1.15 in)、章节标题与卡片标题左侧的细竖线(0.02–0.03 in 宽)、bullets 条目之间的发丝分隔线。**不要用小色块/圆点/图标当行首标记**——那是 AI 生成幻灯最典型的特征,一眼就能认出来;分条职责交给分隔线,强调职责交给粗体导语与主色。
- **暖色**只在极小面积处出现(如 warn 提示的左侧竖线),不承担母题职责。
- **禁止填充色块,不用卡片**:全文不用卡片、胶囊、圆角框;大数字、提示框、表头、标签都不加底色。分区靠线宽差异——标尺线 0.026 in(强)、细线 0.02 in(中)、发丝线 0.007 in(弱)——与留白。实心色块只出现在:封面与结束页的主色带、内容页左上角的章节号块、按需的页底结论横条、致谢/结束页的收尾细带;除此之外,页面上的色只以 ≤12% 浓度的**整幅**色域出现(见下节「背景层」)。
- **公式排版**:LaTeX 经 `formula.py` 渲染为透明 PNG 嵌入(公式字号 20–24 pt,行高 0.55–0.75 in),不用文本框拼上下标;符号表用 12 pt 灰字紧跟公式下方。
- 白底内容页 + 深色封面/结束页的"三明治"结构。内容页禁止大面积色块和满版图片。

### 背景层:直接用真实汇报的素材,不做渐变

`scripts/assets/` 下的三张图是从两份真实的北大汇报里**导出的原件**(ppt/media),不是仿制:

| 素材 | 内容 | 用在哪 |
|---|---|---|
| `pku-landmarks.png` | 大殿 + 华表 + 红楼 + 博雅塔 + 未名湖印章的线描,透明底、自上而下 alpha 渐隐 | plate 封面右下,**画在红带之后**,下半截自然沉进红块 |
| `pku-honeycomb.png` | 蜂窝网格 + 博雅塔剪影,主色约 6% 压白 | split/band 封面与章节页的右上空区 |
| `pku-campus.png` | 未名湖畔的灰度照,最暗仅 223/255 | 致谢页与结束页满版肌理 |

三条规矩:

1. **不做渐变。** 试过用 `<a:gradFill>` 铺同色浓度渐变,投影上一眼假——真实汇报里没有一处
   CSS 式渐变,它们用的是实素材。素材本身自带的 alpha 渐隐是另一回事,那是画出来的。
2. **等比缩放,不拉伸。** 真实汇报里的地标线描被横向拉过 1.455 倍,塔身明显变胖——
   那是手拍坐标的代价,不必跟着犯。
3. **内置素材只在 pku 主题启用。** 校徽与地标是机构专属素材,塞进 azure/pine/plum 就是错的。

**自带底图 `bgArt`**:"首尾页要一层极淡底图"是通用需求,与机构无关,因此任何主题都可以自带:

```js
new Deck({ bgArt: "assets/bg.png" })   // 铺在封面 / 致谢页 / 结束页的最底层
```

传了它就顶掉内置的 `pku-campus.png`,也不再看主题。素材规格照参考件量出来的做法:

- **淡化必须烘焙进 PNG,不要靠渲染器的透明度。** 烘进图里,PowerPoint、LibreOffice、
  导出的 PDF 看到的才是同一张。参考件正是这么做的(XML 里无 alphaModFix)。
- 转灰阶 → 峰值不透明度约 12%(实测参考件最暗像素 223/255,烘出来 224)→
  **竖向不透明度斜坡**,自 55% 高度起显影、上半页保持纯白。均匀压淡会读成
  "一张被冲淡的照片",带斜坡才读成"下缘的一层肌理"。
- 可运行的实现见 `examples/ai-2030-slides/make_bg.py`。

选图有一条:**底图该与论点同源**。那份 AI 算力报告的结论是电力最先咬合,底图就用
输电塔剪影;随便配一张风景只是装饰,配对了才是同一句话的第二遍陈述。

**z 序很要紧**:蜂窝要在实色块**之前**画(让色块盖掉左边一截,这是 Li-S 那份的做法),
地标要在红带**之后**画(让下半截沉进红里,这是 MoS2 那份的做法)。反过来画,
前者会盖住色块、后者会被红带齐齐切一刀。

**内容页一律纯白**,不加任何背景——两份真实 deck 的内容页也都是纯白,零位图零纹理。
- 单位有 VI 主色时,在 THEMES 里加一套(照抄字段结构),不要临时改散落的颜色。

## 中文排版规则(slidekit 机制 + 作者责任)

**机制已保证的**:

- 汉字、全角标点、中文引号破折号 → 中文字体(默认 Microsoft YaHei);拉丁、数字、半角符号 → 西文字体(默认 Arial)。混排文本自动分 run,不需要也不允许手动指定 fontFace。
- 表格用三线表:顶线、底线粗(主色),栏目线细,行间浅线,无竖线——与学位论文/学报规范一致。
- 页码 "03 / 16"、页脚短题、章节 breadcrumb 自动生成。

**作者要自己把住的**:

- 全角标点:中文句子里用 ,。;:、""(),不要混半角逗号句号。数字与单位之间的空格用在西文段里(如 "5% EDS"),slidekit 会给它西文字体。
- 标题断行:两行标题在语义边界断,用 `\n` 手动控制;不要让"的"、"与"落在行首行尾。
- 行长:正文一行不超过 ~28 个汉字当量;更长就该分栏或分页。
- 字体回退:Microsoft YaHei 在装了 Office 的 Windows/Mac 都有;若用户指定 PingFang SC/思源黑体,提醒跨平台观感差异。LibreOffice 渲染预览用的是替身字体,字间距以 PowerPoint 实际打开为准。

## 英文模式(lang:'en')

同一套版式与网格,差异只在:固定文案换英文(Contents/References/Thank You)、中西文都走 latin 字体、目录字距不加宽。英文页标题用简短名词短语(8 个词以内,句子式大小写 Sentence case),不写成完整句子,也不要 Title Case。

## 内容纪律(与版式同等重要)

- 每分钟至多一页内容页;15 min 会议 talk ≈ 12–14 页内容页。
- 一页一个论点;一页至多一个 exhibit(图/表/大数字组三选一为主角)。
- 图上要有"看这里"的标注(paper-figures 生成时就该带上);借用的图页内标出处,文末参考文献页给全条目。
- 结论页(2–4 条要点)放在参考文献之前,Q&A 时停留;结束页只做礼仪功能。
- 全篇未做实验的数值必须标"目标/预期",用 callout(tone:'warn') 声明。
