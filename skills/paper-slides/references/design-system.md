# 设计系统与中文排版规则

slidekit.js 已把这里的大多数规则做成机制;本文档解释"为什么",以及少数需要作者自己判断的地方。

## 画布与网格

- 16:9 宽屏,13.33 × 7.5 in(`LAYOUT_WIDE`)。国内会议室与线上会议的绝对主流。
- 左右边距 0.72 in,内容区宽 12.0 in;内容区底界 6.88 in,页脚基线 7.06 in。
- 块间距 0.26 in;双栏列间距 0.45 in。所有页面同一网格——观众感知不到网格,但感知得到"每页都很稳"。

## 字阶(pt,13.33 in 画布)

| 角色 | 字号 | 说明 |
|---|---|---|
| 封面主标题 | 36 | 粗体,白字,最多三行 |
| 页标题(action title) | 25 | 粗体,主色,至多两行,超两行 slidekit 会警告 |
| 章节页大号数字 | 96 | 极浅主题色,当背景图形用 |
| 章节标题 | 30 | 粗体 |
| 正文 | 17 | 溢出时布局引擎最多降到 ×0.85 |
| 辅文/卡片正文 | 12.5–14 | |
| 图注/表注 | 11.5 | 灰色,居中 |
| 页脚 | 9.5 | 极浅灰,存在但不打扰 |

层级只靠字号 + 字重 + 颜色,不靠换字体。全 deck 一套中文字体 + 一套西文字体。

## 主题与用色纪律

四套内置主题(THEMES):`azure` 藏青·金(通用)、`pine` 墨绿·赭(材料/能源)、`plum` 绛紫·杏(生医/化学)、`pku` 北大红·燕园金(北京大学官方模版配色:北大红 `9A0001` + 燕园金 `CEAB6E`)。每套 = 深主色 + 中亮强调色 + 一个暖色点缀 + 灰阶。字体沿用默认的微软雅黑 + Arial(与官方模版一致)。

### `pku` 主题 = "北大 PPT 模版"的落地(含校徽)

`pku` 是唯一带品牌资源的主题,资源在 `scripts/assets/`(与 slidekit.js 同级,校徽从官方模版矢量抽出、统一到北大红 `9A0001`、透明底):

- `pku-seal.png` 圆形印章 —— **band 式封面/结束页**居中用。封面版式复刻官方模版:白底 + 居中红带,印章整枚坐落白区、下沿切于红带上沿(印章与红带同色,故不让其没入红带),主标题白字居中于带内,下方场合 + 短横线,红带外白区居中放汇报人/单位/日期。结束页同版式,主文字换成"恳请各位专家批评指正"。
- `pku-logo.png` 印章 + 校名横排锁定版(北京大学 + PEKING UNIVERSITY)—— **正文/目录/章节/参考文献页右上角**的角标 logo,等高缩放不变形。

机制由 slidekit 的 `_resolveBrand` 自动接管:选 `pku` 主题即默认引用这两个文件(须把 `assets/` 随 `slidekit.js` 一起复制进用户项目)。可用 Deck 选项覆盖:`logo` / `seal` 传自定义路径,`coverStyle:'plain'` 退回纯色封面,`cornerLogo:false` 关角标,任一传 `false` 关掉;文件缺失静默跳过、不报错。其它主题不带资源,行为不变。

官方模版里的西门石狮、博雅塔满版照片属装饰性满版图,与本 skill"内容页禁满版图"的纪律冲突,故不并入,需要时按 figure 块单独引用。

- **深主色**只用于:封面/结束页底色、页标题、表格粗线、章节标题。
- **强调色**只用于:数字编号、大数字卡数值、章节导航当前项、callout 标签——即"要观众先看"的地方。
- **母题是排版规则,不是装饰色块。** 全 deck 的视觉签名由三种"线"承担:目录/结束页标题下的短标尺线(1.15 in)、章节标题与卡片标题左侧的细竖线(0.02–0.03 in 宽)、bullets 条目之间的发丝分隔线。**不要用小色块/圆点/图标当行首标记**——那是 AI 生成幻灯最典型的特征,一眼就能认出来;分条职责交给分隔线,强调职责交给粗体导语与主色。
- **暖色**只在极小面积处出现(如 warn 提示的左侧竖线),不承担母题职责。
- **禁止填充色块**:卡片、大数字、提示框、表头、标签都不加底色与圆角框。分区靠线宽差异——标尺线 0.026 in(强)、细线 0.02 in(中)、发丝线 0.007 in(弱)——与留白。实心色块只出现在封面色块、致谢/结束页的收尾细带;除此之外,页面上的色只以 ≤12% 浓度的**整幅**色域出现(见下节「背景层」)。
- **公式排版**:LaTeX 经 `formula.py` 渲染为透明 PNG 嵌入(公式字号 20–24 pt,行高 0.55–0.75 in),不用文本框拼上下标;符号表用 12 pt 灰字紧跟公式下方。
- 白底内容页 + 深色封面/结束页的"三明治"结构。内容页禁止大面积色块和满版图片。

### 背景层(只在首尾页)

拆过两份真实的中文学术汇报,它们的母版与版式**都是纯白**,所谓"背景"全部画在页面自身上,
而且语法只有两件东西:**一块实色 + 一片同色系 6%–12% 浓度的区域**
(其中一份的 `#F8F0F1` 就是主色 6% 压白;另一份满版底图最暗只到 223/255 ≈ 12%)。
两份 deck 的**内容页一律纯白,零位图零纹理**——这正好印证了三明治纪律。

据此,slidekit 的背景层只做三件事:

| 页型 | 背景 | 读作 |
|---|---|---|
| 封面 | 实色块 + 从块边缘化开的浓度渐变 | 面 |
| 致谢页 | 只有渐变,**没有**实色块 | 面的影子 |
| 结束页 | 只有一道三级消隐的横线 + 极淡渐变 | 线 |
| 目录/章节/内容页 | 纯白,不加任何背景 | — |

三条硬约束:

1. **必须是真渐变,不能用浓度阶梯拼。** 试过"宽度递增 + 浓度递减"的四级阶梯,
   150 dpi 下实测相邻级差达 ΔRGB (5,12,12),肉眼直接读成条纹——那正是我们要躲的色块。
   pptxgenjs 没有渐变 API,所以画一个纯色矩形当锚点,由 `postProcess` 把
   `<a:solidFill>` 换成 `<a:gradFill>`(与注入切换效果、图表中文字体同一条路子)。
2. **零硬编码色值。** 全部取 `th.primary` + transparency,换主题背景自动跟随;
   这是位图背景做不到的事,也是不采用位图的主要理由。
3. **不学图案。** 真实 deck 里的蜂窝六边形网格与校园地标剪影都**不复刻**:
   规则六边形恰恰是 AI 生成幻灯最典型的背景签名;地标是机构专属,塞进通用模板就是错的。
   要地标的走 `coverArt` 插槽,素材自备。

首尾页在同一条 y = 5.62 上呼应:封面在这条线上是一整块实色(或一条通栏分界线),
结束页缩成"实 1.50 in → 中 3.20 in → 虚 7.19 in"的一条消散横线。同一水平线上一厚一薄,
这一手是从真实 deck 量出来的(它的封面色块上沿与结束页短红线只差 0.035 in)。
- 单位有 VI 主色时,在 THEMES 里加一套(照抄字段结构),不要临时改散落的颜色。

## 中文排版规则(slidekit 机制 + 作者责任)

**机制已保证的**:

- 汉字、全角标点、中文引号破折号 → 中文字体(默认 Microsoft YaHei);拉丁、数字、半角符号 → 西文字体(默认 Arial)。混排文本自动分 run,不需要也不允许手动指定 fontFace。
- 表格用三线表:顶线、底线粗(主色),栏目线细,行间浅线,无竖线——与学位论文/学报规范一致。
- 页码 "03 / 16"、页脚短题、章节 breadcrumb 自动生成。

**作者要自己把住的**:

- 全角标点:中文句子里用 ,。;:、""(),不要混半角逗号句号。数字与单位之间的空格用在西文段里(如 "5% EDS"),slidekit 会给它西文字体。
- 标题断行:两行标题在语义边界断,用 `\n` 手动控制;不要让"的"、"与"落在行首行尾。
- 行长:正文一行不超过 ~28 个汉字当量;更长就该分栏或分页。
- 字体回退:Microsoft YaHei 在装了 Office 的 Windows/Mac 都有;若用户指定 PingFang SC/思源黑体,提醒跨平台观感差异。LibreOffice 渲染预览用的是替身字体,字间距以 PowerPoint 实际打开为准。

## 英文模式(lang:'en')

同一套版式与网格,差异只在:固定文案换英文(Contents/References/Thank You)、中西文都走 latin 字体、目录字距不加宽。英文 action title 用句子式大小写(Sentence case),不要 Title Case。

## 内容纪律(与版式同等重要)

- 每分钟至多一页内容页;15 min 会议 talk ≈ 12–14 页内容页。
- 一页一个论点;一页至多一个 exhibit(图/表/大数字组三选一为主角)。
- 图上要有"看这里"的标注(paper-figures 生成时就该带上);借用的图页内标出处,文末参考文献页给全条目。
- 结论页(2–4 条要点)放在参考文献之前,Q&A 时停留;结束页只做礼仪功能。
- 全篇未做实验的数值必须标"目标/预期",用 callout(tone:'warn') 声明。
