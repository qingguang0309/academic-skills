# 北京大学风格 Word 文档规范

创建任何 Word 文档时，一律应用以下规范。内容生成流程遵循 docx skill，本 skill 约束版式与文风。

## 版式规范

### 颜色

全文只用一种强调色：北大红（#94070A）。除正文黑色外，不引入第二种颜色。所有标题、页眉标题、页眉分隔线一律北大红，避免多色堆砌。

### 页眉

- 左侧：北京大学 logo（本 skill 自带资源 `assets/pku_logo.png`），尺寸固定为宽 0.95 in × 高 0.22 in。
- 右侧：文档大标题（即文档的一级总标题），与 logo 同一行，右对齐。字体 Microsoft YaHei，9 pt，颜色北大红（#94070A）。标题过长时可用简短版本，但须与封面/正文主标题一致。
- 页眉下方插入一条分隔线：北大红（#94070A）、0.5 pt 单线，与正文分隔（脚本已通过段落下边框实现）。

### 标题颜色

- 全文各级标题（Title、Subtitle、Heading 1–9，即所有级别）统一使用北大红（#94070A），不用 Word 默认蓝色，也不逐级换色。
- 脚本对标题做两层保证：样式级设色 + 段落级逐 run 兜底染色（含落在表格内、或带局部颜色格式的标题），确保任何级别的标题都是北大红。
- 正文、参考文献、图表标注等正文性内容保持黑色，不染红。

### 字体

原则：整体优雅、克制，中西文分设，不混用花哨字体。

- 正文：中文宋体（SimSun），西文 Times New Roman。正式长文用宋体更显沉稳；偏展示性的短文档可整体换 Microsoft YaHei，但全文统一。
- 各级标题：中文 Microsoft YaHei，西文 Arial。
- 参考文献：英文条目一律 Times New Roman（随正文默认即可，不得混入其他西文字体）。
- 其他位置的英文按语境选 Times New Roman（正文、引文、文献）或 Arial（标题、图表标注），不引入第三种西文字体。

### 页脚

- 居中插入页码，格式严格为：`第X页/共X页`。
- 必须用 Word 域实现（PAGE 和 NUMPAGES），不能写死数字，否则增删页后页码错误。

### 实现方式

直接运行自带脚本，在文档内容生成完毕后应用页眉页脚：

```bash
python scripts/apply_style.py <文档.docx> --title "文档大标题"
```

脚本会插入 logo、页眉标题、北大红分隔线、页码域，把各级标题统一染为北大红，并设置全文默认字体（正文宋体+Times New Roman，标题微软雅黑+Arial）后保存。若脚本因环境问题不可用，参照脚本源码用 python-docx 手工实现同样效果（脚本内有注释）。

## 技术文档的额外要求

判断标准：凡涉及专业知识、实验、数据、方法、工程方案、文献综述的文档均算技术文档。

- 文末必须有"参考文献"（或"参考资料"）一节。学术内容用规范引文格式（默认 GB/T 7714，英文文献可用原格式）；网络资料给出标题、来源、URL、访问日期。
- 正文中的引用处标注编号（如 [1]），与文末列表对应。
- 需要补充说明但不宜打断正文的内容，使用脚注（页面底部），不要塞进正文括号里。
- 不得虚构参考文献。找不到可靠来源时，明确标注"待补充来源"，而不是编一条。

## 文风要求

### 去除AI味

写出来的东西要像一个专业的人写的，不像模型生成的：

- 禁用套话开头："在当今……的时代"、"随着……的发展"、"众所周知"。直接进入主题。
- 禁用空洞收尾："总而言之"、"综上所述，……具有重要意义"。结尾给结论或行动项，说完即止。
- 少用排比堆砌和"赋能、抓手、闭环、颗粒度"之类的空词。
- 以段落叙述为主，不要满篇 bullet 和加粗。列表只在真正枚举并列项时使用。
- 句长有变化，允许短句。不要每段都是"首先/其次/最后"的模板。
- 不加不必要的免责声明和客套（"希望对您有帮助"之类一律不写）。

### 直接、结论先行

- 结论先行：每节第一句给出该节的判断或结果，然后再给论证和数据。
- 直接、简洁：能删的词都删掉；不绕弯、不铺垫、不重复。
- 逻辑链完整：观点必须有依据（数据、文献、推理），依据不足就明说不足。
- 不迎合、不夸饰：如实陈述局限和风险，不用形容词代替论证。
- 结构服务于逻辑：标题层级反映论证结构，而不是为了好看而分节。

## 交付前自查

1. 页眉：左 logo（0.95×0.22 in）、右标题（雅黑、北大红）、下方 0.5 pt 北大红分隔线齐全？
2. 页脚："第X页/共X页"是域而非死数字，总页数正确？
3. 颜色：全文各级标题均为北大红（#94070A），除正文黑色外无其他颜色？
4. 字体：正文宋体+Times New Roman、标题雅黑+Arial、参考文献英文全为 Times New Roman？
5. 技术文档：参考文献齐全、编号对应、无虚构来源？
6. 通读一遍：删掉所有套话；每节是否结论先行？
