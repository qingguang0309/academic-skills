# XHS Post —— 把学术/技术产出转成小红书图文

你现在的角色不是"排版工具",而是**替作者判断这份内容在信息流里能不能被打开**。
小红书上最常见的失败不是图丑,是三件事:首图没有信息、正文页在手机上看不清、
文案写成了"我做了个很美的东西"。这三件都不是设计问题,是选择问题。

## 五条铁律

1. **先出图,再写文案。** 文案要引用图里的具体数字与页序,图没出就只能写空话。
   顺序反了,文案会变成通用模板。

2. **3:4 是硬约束,不是建议。** 小红书信息流按 3:4 展示,16:9 幻灯直接上传会被
   自动裁掉左右两侧——正文那一列会整个没掉。必须放进 1080×1440 画布居中,
   **宁可上下/左右留白,也不裁内容**。脚本已实现,不要手工缩放。
   - 16:9 幻灯 → 留白在上下,占比大,属正常
   - A4 竖版(1:1.414)→ 留白在左右,很窄,几乎看不出

3. **18 张上限,超了必须显式取舍。** 超出时脚本会报警。用 `--only` 挑页,并在
   交付说明里写清**删了哪几页、为什么**。静默截断会让作者以为全都发出去了。

4. **首图决定打开率,而首图往往不该是封面。** 整页的密集正文/公式在手机上字太小,
   没人会放大看。首图应当放**一眼能看懂结论的那张图**(数据图、对比图、流程图),
   把封面和正文页排在后面当"完整版在这"的证据。这一条要主动向作者建议,
   不要因为原顺序是封面在前就照搬。

5. **数字只能来自实际产物。** 文案里的页数、耗时、指标、对比值,一律取自真实生成的
   文件与终端输出;记不准的就不写。编一个"三天做完""效率提升 10 倍"很容易,
   但作者要为它负责,而你不在场。

## 工作流程

### 第 1 步:问清或合理默认

- **发布主体**:个人分享 / 课题组 / 商业账号?决定文案人称与是否露出联系方式。
- **目标读者**:同行 / 学生 / 泛技术人群?决定术语密度。泛读者向要把"为什么值得看"
  提到第一段,同行向可以直接上结论。
- **是否已有成稿**:有 PPT/PDF 就直接转;只有论文或数据,先走 paper-slides 做 deck,
  本 skill 只负责"已完成产出 → 社交图文"这一段。

### 第 2 步:出图

```bash
python3 scripts/deck2xhs.py talk.pptx -o xhs
python3 scripts/deck2xhs.py paper.pdf -o xhs --dpi 200
python3 scripts/deck2xhs.py talk.pptx -o xhs --only 1,4-9,12,15-19   # 超 18 张时挑页
```

产出两套:

| 文件 | 用途 |
|---|---|
| `xhs-01.png` … | 3:4(1080×1440),**上传这套** |
| `page-01.png` … | 原始比例高清图,需要横版或二次加工时用 |

脚本已挡住三处坑,不要绕过它手工处理:

- `pdftoppm` 对个位数页码不补零,`page-1`/`page-10` 按名排序会变成 1,10,11,2…
- 留白底色从页面四角采样,不写死纯白——暖白/米色版式配纯白留白会露出一圈边界
- 超过 18 张时报警而不静默截断

**出图后必须用 Read 亲眼看几张**:确认没有裁切、没有留白色差、文字在手机尺寸下可读。
把首图、一张内容页、末页各看一遍。

### 第 3 步:定图序

默认顺序是原页序,但**要主动评估首图**。判断标准只有一条:
在手机信息流里缩略显示时,**这张图能不能三秒内让人知道值不值得点开**。

- 能:数据图、对比图、结论页、有强反差的流程图
- 不能:整页正文、公式推导页、参考文献页、只有标题的封面

若首图不合格,把最有信息量的那张提到第一位,原封面往后放。这个调整要向作者说明理由。

### 第 4 步:写文案

**1000 字以内**(用户没另行指定时),结构见 [references/copywriting.md](references/copywriting.md)。
核心只有一句:**写机制与踩坑,不写"我做了个很美的东西"**。后者在小红书上同质化极重,
前者有具体信息量,也才配得上前面那些图。

写完自查:

- [ ] 每个数字都能在生成的文件或终端输出里找到出处?
- [ ] 有没有"赋能""闭环""干货满满""建议收藏"这类词?(见 copywriting.md 的词表)
- [ ] 第一段读完,读者知道这篇要给他什么了吗?
- [ ] 有没有至少一处"我踩了什么坑"?——它比任何形容词都可信
- [ ] 结尾是不是在求赞/求关注?去掉。

### 第 5 步:交付

给作者一个目录 + 一份 `copy.md`,并**说清三件事**:

1. 传哪一套图(3:4 那套)、为什么另一套也留着
2. 图序是否调过、调了什么、为什么
3. 若超过 18 张,删了哪几页

## 已知限制

- 小红书的图片上限与展示比例由平台决定,本 skill 按当前的 18 张 / 3:4 实现;
  平台改规则时改 `scripts/deck2xhs.py` 顶部的 `XHS_MAX` 与 `XHS_W/XHS_H`。
- 本 skill 不发布、不登录、不代操作账号,只产出文件。发布由作者本人完成。
- 转换依赖 LibreOffice(`soffice`,仅 pptx 需要)与 poppler(`pdftoppm`)。
